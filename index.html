Bhor Analytics

A private-use analytics and reporting system developed to understand the performance of the BHOR YouTube channel.

About the application

Bhor Analytics connects to Google and YouTube APIs with the channel owner's authorization. It collects channel statistics, video performance metrics, traffic sources, and audience retention data for historical tracking and analysis.

How it works

The application processes analytics data using Python and stores structured records in a private database. Backups are maintained in an access-controlled Google Drive account.

Who uses it?

Bhor Analytics is an internal tool intended for its owner. It is not offered as a public analytics service.
